# 俄罗斯方块 · 炫彩版

霓虹暗色风的经典俄罗斯方块网页小游戏，手机和电脑都能玩。

- 在线：https://liuzhuoling2011.github.io/tetris/
- 操作：←→ / A D 移动，↑ / W 旋转，↓ / S 软降，空格硬降，P 暂停
- 规则：七种方块，消行得分；等级随消行提升，下落加快；预览下一个方块
- 本地记录最高分（`localStorage`）
- 纯静态页面，无构建步骤

## 本地预览

直接打开 `index.html`，或：

```bash
python3 -m http.server 8080
```

浏览器访问 `http://localhost:8080/`。
